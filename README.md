# Yatzy Battle

A modern, responsive Yatzy game built with HTML, CSS, and JavaScript.

## 🎲 Features
- **Mobile First**: Optimized for both PC and Mobile devices.
- **Modern UI**: Smooth animations and premium design.
- **No Dependencies**: Pure vanilla JavaScript for fast loading.

## 🚀 How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Randyflourish/Yatzy-Battle.git
   ```
2. Open `index.html` in your favorite browser.

## 🌐 Deployment
This project is designed to be hosted on **GitHub Pages**.
