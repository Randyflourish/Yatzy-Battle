# Yatzy Battle Specification

## Overview
Yatzy Battle is a roguelike, turn-based game where player use five dice to battle on their way of exploring the dungeon.

## Game Rules
- One player. Can play on PC or Mobile.
- The goal is to go through a dungeon as far as players can.
- There will have a rougelike map, and players cannot go back to a room they have already visited.

## Map Generating Rules
- For each floor, there will have a map with 11 stage.
- Each stage will exist 2 ~ 3 rooms. Only the first and the final stage will exist 1 room.
- Each room will have 1 ~ 3 roads to the room in the next stage. Some of the room in the next stage may not reach by the road. The probability of 2 or 3 roads is 75 %
- The map will be generated by a random algorithm.
- The map will show the current room and all possible room for the next 3 stages.
- Roads should not have any intersection.
- When player click an available room, the player will go to the room.
- Player start at the **Start** room.
### Room Types
- **Start**: The starting room. Player will born in this room in the start of each floor. Have no back. Use nothing to represent.
- **Battle[Normal]**: The normal battle room. Player go this room will have a battle with 1 ~ 3 enemies. After winning the battle, player might gain some reward like golds or items. Use a normal monster icon to represent.
- **Battle[Elite]**: The harder battle room. Like **Battle[Normal]**, player will have a battle against 1 ~ 3 stronger enemy. The reward, compareing with **Battle[Normal]**, will become better. Use a elite monster icon to represent.
- **Treasure**: The treasure room. Player go this room will have a chance to get some reward like golds or items. Use a treasure icon to represent.
- **Shop**: The shop room. Player go this room will have a chance to use golds to buy some items. Use a shop icon to represent.
- **Rest**: The rest room. Player go this room will have a chance to rest and recover some HP. Use a cross icon to represent.
- **Event**: The event room. Player go this room will trigger a random event, and the event might have some effect on player. Use an exclamation mark icon to represent.
- **Partner**: The partner room. Player go this room will have a chance to get a partner. Use a partner icon to represent.
- **Boss**: The final battle room for each floor. Player go this room will have a battle against 1 ~ 3 boss enemy. The reward, compareing with **Battle[Elite]**, will become much better. Use a boss monster icon to represent.
- All icons are in the `assets` folder.

## Battle Rules
### Phase Flow
- **Player Action**: Player can choose to 1. Attack 2. Use Item 3. Use Skill. 4. Choose the main target to attack. Only the 1st action will move into next phase. 
- **Player Roll**: Player roll five dice, and have 3 chance to roll again. Player can choose which dice to roll again.
- **Player Attack**: Player attack the main target, and the damage will be calculated by the dice result. Some additional skills of character might happen according to the dice category.
- **Enemy Attack**: All Enemy CD-1. If any enemy's CD is 0, then it will attack the player, and the damage will be calculated by the dice result. Some additional skills of enemy might happen according to the dice category. Finally, the CD will be reset (each enemy have different CD).
- Go back to the first phase.
### Dice Categories
- **Number of Ones**: Number of dice with value 1.
- **Number of Twos**: Number of dice with value 2.
- **Number of Threes**: Number of dice with value 3.
- **Number of Fours**: Number of dice with value 4.
- **Number of Fives**: Number of dice with value 5.
- **Number of Sixes**: Number of dice with value 6.
- **Number of Same**: Maximum number of dice with the same value.
- **Full House**: 3 dice with the same value and 2 dice with the same value. (The two values can be either the same or different)
- **Straight**: Maximum number of dice with consecutive values.
- **Sum**: Sum of all five dice.
- **Odd/Even**: Number of dice with odd/even value.
- **Big/Small**: Number of dice with big/small value.
